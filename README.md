# About Page
Hello! This is my website for all the PuzzleScript htmls I collected.   
I made this because downloading each html to play was tedious, so I put them all in one place without a need to download.

if you want a far more thorough database, go [here](https://pedrosworks.com/articles/puzzlescript-database)

All of these games are publicly available online, here are the websites where I got most of the htmls.   
[itch.io](https://itch.io/games/tag-puzzlescript), [increpare games](https://www.increpare.com/categories/puzzlescript.html), [Erich Friedman's Interactive Puzzles](https://erich-friedman.github.io/published/interactive.html), [Pedro's Selected PuzzleScript Games](https://pedrosworks.com/articles/selected-games), [PuzzleScript Gallery](https://puzzlescriptgallery.tumblr.com/), [PuzzleScript Plus Gallery](https://auroriax.github.io/PuzzleScript/Gallery/index.html), [PuzzleScript Next Gallery](https://puzzlescriptnext.polyomino.com/Gallery/index.html)

This website has around 800 htmls. there are far more that I could collect, but I think im tuckered out for now. The main websites I could get more htmls from are itch.io and the full database linked above.   
There is a lot of shortcomings with this collection, so please be nice. The filenames are not standardized, and there may be capitalization differences, symbol differences, spacing differences, and what not. The name listed in the html is accurate, not the filename. There are also no dates or creators listed in the collection, but you can still see the creator listed in the game.   
Since these games are all free and publicly available, i hope this isn't illegal? If youre the creator of one of the games on here, you can ask me to take it off of this website.
