# collected puzzlescript games
hello. i have collected around 700 puzzlescript games.

this is by no means a database of all of them, here is a more thorough [database](https://pedrosworks.com/articles/puzzlescript-database)

I obtained these from various other sources online:

[itch.io](https://itch.io/games/tag-puzzlescript), [increpare games](https://www.increpare.com/categories/puzzlescript.html), [Pedro's Selected PuzzleScript Games](https://pedrosworks.com/articles/selected-games),
[PuzzleScript Gallery](https://puzzlescriptgallery.tumblr.com/), [PuzzleScript Plus Gallery](https://auroriax.github.io/PuzzleScript/Gallery/index.html), [PuzzleScript Next Gallery](https://puzzlescriptnext.polyomino.com/Gallery/index.html). There may be other sources i forgot but these are the main ones

There are still a lot more puzzlescript games for me to obtain, but im a bit too lazy too. I have not gone through the entirety of itch.io or the full database linked above. because i dont want too and thats too much. 
Since puzzlescript games are also accessed through links, one could theoretically make a bot to access each possible link, see if theres a game, then download the html for it. this is way beyond my power, im barely able to make this github page.

Please excuse the shortcomings of this collection. There are no dates or credit to creators on anything, besides whats provided in the html. I also make a lot of mistakes so tell me if something is broken. If you dont want your game on here please tell me as well. All of these games are freely available to download online so i dont think this is illegal. (i hope)
